# BOK WATCH 3.0 — 3단계: 백테스트 사전 등록(프로토콜)

이 문서는 결과를 보기 **전에** 커밋한다. 이후 결과를 보고 표본·시계·지표·모형 설정을 바꾸지 않는다. 바꾸면 변경 사유와 날짜를 이 문서 끝에 덧붙이고, 결과 표에 "프로토콜 변경 후"로 표시한다.

## 표본
- 회의: `data/meetings_history.csv`의 금통위 2008-01-10 ~ 2026-10-22 (자료가 있는 회의만). 2026-11-26은 금리 자료가 11/12에서 끝나 제외한다.
- 결과: 회의일 기준금리 변화(ECOS 722Y001 일별). 인상(+)·동결(0)·인하(−)로 분류, 변화폭은 기대금리 오차 평가에만 쓴다.
- 금융위기 구간(2008-09~2009-03)을 제외하지 않는다. 국면별 표에서 따로 본다.

## 예측 시계와 관측 시점
- 시계 D = 회의 N일 전(달력일): 60, 30, 14, 7, 1.
- 관측일 = 회의일 − D 이전의 마지막 영업일 종가(15:30). D=1은 회의 전날 종가. 회의 당일 오전 예측은 직전 영업일 종가와 같아 D=1 칸과 겹치므로 따로 만들지 않는다.
- 각 회의는 시계마다 칸 1개를 만든다. 모든 평가는 회의 단위로 집계한다(칸 수가 아니라 회의 수가 표본 크기).

## 학습·검증·최종 평가 구간
| 구간 | 회의 | 용도 |
|---|---|---|
| 학습 전용 | 2008 ~ 2011 | 모형 추정 초기화(평가에 쓰지 않음) |
| 개발·검증 | 2012 ~ 2019 | 모형 비교, 설정 점검 |
| 검증 | 2020 ~ 2022 | 개발 단계 설정 확인 |
| **최종 평가(격리)** | 2023-01 ~ 2026-10 | 한 번만 본다. 이 구간 결과를 보고 모형을 고치지 않는다 |
- 2023-02 이후가 합성 KOFR OIS를 쓸 수 있는 구간이라, OIS 계열 모형과 현재 운영 50:50은 이 구간에서만 비교한다.

## 학습 방식
- 모든 추정은 관측일까지의 자료만 쓰는 확장 창이다. 곡선 모형(DNS·ACM)은 13주마다 다시 추정하고 최소 156주를 쓴다.
- 조정 가능한 설정은 사전에 고정한다: DNS 감쇠 λ=0.0609(월 단위), ACM 요인 K=3, 확률 변환은 운영 코드의 `model.move_distribution`. 이 값들을 결과를 보고 바꾸지 않는다.
- 가중치를 배우는 모형(M4·M11)은 이전 회의의 예측과 결과만으로 정한다. 최종 평가 구간의 결과는 가중치 선택에 쓰지 않는다.

## 모형 목록(1차)
M0 항상 동결 · M0b 과거 빈도 · M2 통안채 91일 단독(운영 산식 그대로) · M7 DNS-VAR(수익률곡선 요인 예측) · M5 ACM-VAR(P측도 기대 정책금리). 합성 OIS(M1)·운영 50:50(M3)은 최종 평가 구간에서만 비교한다. 후속 모형(M4·M6·M8~M11)은 같은 틀로 추가하고, 그 때마다 이 문서에 날짜와 함께 덧붙인다.

## 지표
Brier(3분류), Brier Skill Score(기준: M0b), 로그손실(확률 하한 1e-3), 보정표(인상 확률 구간별 실제 빈도), 변별력(확률 분포의 평균 편차), 변경 알림 정밀도·재현율(변경 확률 ≥ 0.5), Balanced Accuracy(argmax), 기대금리 MAE.
- 모형 간 차이는 회의 단위 부트스트랩(10,000회)으로 신뢰구간을 낸다.
- 구간별: 전체, 인상기·인하기·동결기(관측일 직전 12개월 기준금리 변화로 정의, 미래 정보 없음), 실제 변경 회의, 시계별.

## 해석 원칙
- Brier만 보지 않는다. 동결이 많은 표본에서는 항상 동결·빈도 모형도 점수가 좋게 나오므로 BSS와 변경 회의 성능을 함께 본다.
- 표본이 작은 구간(인상기 등)은 신뢰구간을 같이 적고 단정하지 않는다.
- 이번 11/26 결정(계기가 된 사례)은 최종 검증 사례로 쓰지 않는다.

## 프로토콜 추가 (2026-11-26, 1차 결과 확인 후 · 2차 실행 전)
1차 결과(04)를 본 뒤 모형을 더 넣는다. 아래는 결과를 보고 추가하는 것이므로 2차 결과는 "프로토콜 추가 후"로 표시한다. 1차에서 이미 돌린 모형의 설정은 바꾸지 않는다.
- **M4a 통안채+빈도 시계별 축소**, **M4b DNS+빈도 시계별 축소**: p = w_D·p_모형 + (1−w_D)·p_빈도. w_D는 시계 D별로 이전 회의들의 Brier를 최소화하는 값을 0.1 격자에서 고른다(이전 회의 20개 미만이면 w=0.5). 가중치 선택에 그 회의와 이후 결과를 쓰지 않는다.
- **M1 합성 OIS 단독**, **M3 운영 50:50(합성 OIS + 통안채 91일)**: 운영 코드(`awm_data.ois_model`)를 그대로 쓰고, OIS가 계산되는 2023-02 이후 칸에서만 평가한다. 비교는 OIS가 가능한 칸의 공통 표본에서 한다.
- 평가 지표·구간·부트스트랩은 1차와 같다.

## 프로토콜 추가 2 (2026-11-26, 2차 결과 확인 후 · 3차 실행 전)
- **M8 회의일 기반 풀이(최대 엔트로피)**: 통안채 91일 금리 한 식으로 만기 안의 모든 회의를 날짜·적용 일수(`model.exposure_days`)로 직접 반영한다. 식은 하나라 회의별 확률이 유일하지 않으므로, 회의마다 독립인 과거 빈도 사전분포에서 시작해 기대 금리 제약을 만족하는 쪽으로 정보량이 가장 적게 움직인 분포(지수 기울임, KL 최소)를 쓴다. 정상 스프레드는 운영 산식과 같은 `market.pit_spread`. 기울임 강도는 이분법으로 정하고 조정 모수가 없다.
- **M11 동적 앙상블**: 구성원 M0b·M2·M7·M8을 시계 D별로 과거 회의의 평균 Brier로 가중한다. 가중치 ∝ exp(−10·평균 Brier). 이전 회의가 10개 미만이면 균등. 10은 사전 고정값이며 결과를 보고 바꾸지 않는다. OIS 계열(M1·M3)은 전 구간에 없어 구성원에서 제외한다.
- 평가 지표·구간·부트스트랩은 1·2차와 같다. 3차 결과는 "프로토콜 추가 2 후"로 표시한다.

## 프로토콜 v3 (2026-11-27, 사용자 추가 지시 반영 · 이후 모든 실행 전에 커밋)
2·3차 결과에서 쓴 최종 평가 구간(2023~)은 이미 여러 번 열어 보았다. **이 구간은 완전히 독립적인 최종 검증 표본으로 간주하지 않는다.** 전향적 검증(실제 금통위 예측의 사전 기록)을 별도로 구축하고 그 결과만 독립 검증으로 인정한다. 아래 정의는 신규 결과를 보기 전에 고정한다.

### A. 지표 정의 통일
- **Brier(3분류)** B = Σ_c (p_c − 1[실제=c])², c∈{인상, 동결, 인하}. 범위 0~2, **정규화하지 않는다**. 참고로 B/2(0~1)를 함께 적을 수 있다.
- **BSS** = 1 − B_모형 / B_과거빈도(M0b). 기준은 항상 M0b이다.
- **로그손실** 확률 하한 1e-3. **극단적 오판** = 실제 결과에 준 확률이 0.05 미만인 칸의 비율.
- **변경 알림** = 인상+인하 확률 ≥ 0.5. **재현율 = 알림이 울린 변경 칸 / 실제 변경 칸**, **정밀도 = 변경 칸 / 알림 칸**. 분모는 항상 "칸(회의×시계) 수"이며 결과 표에 칸 수를 적는다(최종 구간 실제 변경 7개 회의 × 5시계 = 35칸).
- **정책 전환점** = 결정 분류가 직전 회의의 결정 분류와 다른 회의(동결→변경, 변경→동결, 인상↔인하). 전환점 회의에서 따로 평가한다.
- **예측 확률 안정성** = 같은 회의에서 인접한 시계(60→30→14→7→1) 사이 인상 확률 변화 절댓값의 평균.
- **예상 기준금리 경로 정확성** = 기대 변화의 MAE(bp).

### B. 표본 구분
- **공통 격자**: 비교하는 모든 모형이 같은 칸에서 예측한 칸만 쓴다. 칸 수와 회의 수를 같이 적는다.
- **최대 가용 표본**: 모형이 예측할 수 있는 모든 칸. 모형마다 표본이 다르므로 서로 직접 비교하지 않는다.
- 시계별 차이의 통계적 불확실성은 시계마다 회의 단위 부트스트랩(10,000회)으로 따로 구한다.

### C. 대표 모형 선정 기준(사전 등록)
후보가 아래를 모두 충족해야 "자격 있음"으로 본다. 자격 있는 모형 중 Pareto 최적 집합(전체 Brier·변경 회의 Brier 동시에 열위가 아닌 모형)을 추천하고, 같은 수준이면 단순하고 운영 비용이 낮은 모형을 우선한다.
1. 개발·검증 구간(2012~2022)에서 전체 Brier 차이(모형 − M0b)의 95% 구간 상한이 +0.05 이하(기준보다 의미 있게 나쁘지 않음).
2. 변경 회의(개발·검증+최종 합산)에서 재현율 ≥ 0.40이고 변경 회의 Brier가 M0b보다 낮음.
3. 극단적 오판 비율이 운영 50:50(M3)과 같거나 낮음(OIS 구간 공통 격자).
4. 어느 시계에서도 M0b보다 Brier가 +0.10 넘게 나쁘지 않음(최종 구간 포함 5개 시계 모두).
5. 인상 확률을 인위적으로 키우거나 임계값을 조정해 재현율을 높이는 방식 금지.
이 기준은 이후 결과를 보고 바꾸지 않는다. 전향적 검증이 쌓이기 전에는 어떤 모형도 대표로 확정하지 않는다.

### D. 제로 커브·AFNS 사양(고정)
- **제로 커브**: 국고채 1·3·5·10년 만기수익률(액면 이표채, 연 2회 이자)을 0.5년 격자에서 PCHIP 보간한 뒤 부트스트래핑해 무이표(연속복리) 금리로 바꾼다. 1년 이하(통안채 91일·국고채 1년)는 이미 무이표로 취급한다. 국고채 곡선과 통안채를 섞은 곡선은 만들지 않는다. 변환 전후 차이를 기록한다.
- **AFNS(독립요인형, Christensen·Diebold·Rudebusch 2011)**: 요인 3개(수준·기울기·곡률), Q측도 평균회귀 행렬은 Nelson-Siegel 구조, 위험중립 평균 0, P측도는 대각 평균회귀. 수익률 조정항은 Riccati 해를 수치 적분으로 계산한다. 주간 제로 수익률(0.25·1·3·5·10년)을 칼만필터 최대우도로 추정(확장 창, 연 1회 재추정, 최소 156주). 단기금리 r = 수준+기울기. 모수·초깃값은 결과를 보고 바꾸지 않는다.
- **ACM**: 기존 구현(요인 3개)을 제로 수익률로 다시 추정한 `M5z`와 기존 `M5`를 모두 평가한다.
- 개별 회의 확률은 위 모형의 기대 단기금리만으로 유일하게 정해지지 않는다. 기대 경로에서 확률로 바꿀 때 M8(최대 엔트로피)을 쓰며, 가정(사전분포·허용오차)을 결과 표에 적는다.

### E. 신규 모형(고정 정의)
- **M12** = M8, 단 정상 스프레드에 ACM이 추정한 기간프리미엄의 훈련 평균 대비 편차를 더해 보정한다. **M13** = AFNS의 P측도 기대 경로(만기 91일 구간 평균 단기금리 변화)를 M8의 제약식 L로 쓴다. **M14** = M8과 운영 50:50의 확률 단순 평균(OIS 구간). **M15** = M8과 M11의 단순 평균. **M16** = 시계별 Mixture of Experts: 전문가 M8·M2·M7과 M0b, 가중치는 시계 D의 로그에 대한 가우시안 커널(대역폭 0.7)로 이웃 시계의 과거 Brier를 평활해 연속적으로 정함(가중치 ∝ exp(−10·평균 Brier)). **M17** = 국면별 앙상블: 관측일 직전 12개월 기준금리 변화로 국면(인상기·인하기·동결기)을 정하고, 국면×시계별로 M8·M2·M7·M0b를 같은 방식으로 가중.
- **M8 변형(민감도, 선정에 쓰지 않음)**: 사전분포 = 과거 빈도(기본), 균등(순수 최대 엔트로피), 동결 편중(0.9), 직전 결정 맥락별 빈도. 허용오차 ε=2bp·T로 식별 가능한 확률 범위(구간)를 별도 계산한다.
- **M11 민감도(선정에 쓰지 않음)**: η∈{2,5,10,20,50}, 구성원 제거(leave-one-out), 구성원별 평균 가중치(국면별), 정규화 스태킹. **M11은 η=10 그대로** 평가한다.
- **확률 교정**: 로그잇 스케일 한 모수 a(0.5~1.5, 0.1 격자)를 학습 구간(확장 창, 최소 40개 회의 이후 칸)에서만 정하고 표본 외 평가. 더 복잡한 함수는 쓰지 않는다. 교정 전후 Brier·보정표를 같이 낸다.

### F. 제약
- 운영 대표 모형·운영 화면은 바꾸지 않는다. 신규 결과로 대표 모형을 확정하지 않는다.
- 최종 구간을 반복해서 열어 모형을 고치지 않는다. 이미 연 구간이므로 결과 표에 "재사용 구간"으로 표시한다.
