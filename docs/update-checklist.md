# BOK워치 갱신 체크리스트

매일 오전 10시 자동 갱신(GitHub Actions `daily`) 뒤 사람이 확인한다. 수시 갱신(오후·저녁)도 같은 순서.

## A. 자동 갱신 확인

1. **자동 갱신 성공** — GitHub Actions `daily`가 성공했는지, 단계별 실패가 없는지. 09:40 KST 전후에 `workflow_dispatch`로 시작했는지(Cloudflare 크론 `bokwatch-cron`) 본다. 14시 넘어 `schedule`로만 시작했다면 크론 호출이 실패한 것이다.
2. **수집 기준일** — 화면 머리말 '갱신' 점에 마우스를 올려 9곳을 본다.
   - ECOS 시장금리·CD 91일: 전 영업일
   - 금투협 CD 시가평가(자체 합성 OIS 입력): 전 영업일. 해외 서버에서 막히면 OIS가 멈춘다
   - KRX KOFR 선물, KOFR 익일물: 전 영업일(KOFR는 하루 늦을 수 있음)
   - 한은 홈페이지, 연합뉴스·네이버, 지표 일정, AI, 결정 예측 모형
3. **날짜별 확률 기록** — 오늘 줄이 '산출'로 남았는지(중단이면 사유 확인).
4. **AI 정성 판단은 갱신 때마다 반드시 함께 돌린다** — 뉴스 수집(연합·네이버) 직후 AI 태깅·사건 묶기·종합 판단까지. 수시 갱신(오후·저녁)도 예외 없음. 판단 시각이 갱신 시각과 맞는지 확인.

## B. 사람이 채우는 것

5. **총재 발언 타임라인**
   - 전날 갱신 이후 총재 발언 검색(기사 제목 '신현송'·'한은 총재'), 원문 기사와 대조해 직접 인용만 넣는다.
   - 금리·물가와 무관한 발언(제도·사과 등)은 넣지 않는다.
   - 직전 발언과 사이가 비면 그 기간 발언을 따로 찾는다(간담회·국회·해외 행사·면담).
   - 자동으로 붙은 '관련 기사'가 다른 자리 기사로 섞이지 않았는지 본다.
6. **기관 전망(보고서 탭)** — 전망 집계는 최근 5영업일 안에 나온 보고서만 들어간다. 오래된 기관은 새 보고서가 나오면 갱신한다.
   - 연합인포맥스 '[금통위 인터뷰]', 금통위 프리뷰·설문, 채권포럼·세미나 기사를 찾는다.
   - 원문에서 다음 회의·그다음 회의 전망, 소수의견, 최종금리·시점을 확인해 넣는다. 원문을 못 보면 넣지 않는다.
   - 옛 연도 기사(예: 2021·2025년 같은 달)를 걸러낸다.
7. **금투협 채권시장지표 설문** — 금통위 직전 주(다음 달 이름으로 발표, 예: 10월 회의 → '11월 채권시장지표')에 동결·인상·인하 응답 비율.
8. **지표 실제치·예상치** — 미국 CPI·PPI·고용, 한국 CPI 실제치를 BLS·ECOS 원자료와 대조. 시장 예상치(컨센서스)는 보도 확인 뒤 입력.
9. **AI 판단 검수**
   - 서로 다른 사건이 한 사건으로 묶이지 않았는지(보도 수가 비정상적으로 큰 사건).
   - '사건 분류와 요약 대조'에 '다름'이 있으면 이유를 본다.
   - 연준 쪽 신호가 한은 신호로 섞이지 않았는지.
10. **일정 변화** — 2027년 금통위 일정 공지 여부(공지되면 1월 가정 회의를 실제 날짜로), 임시회의·일정 변경.

## C. 배포 뒤 대조

11. **고정 요약 카드 4개(맨 위 박스) 갱신 확인** — 카드마다 아래 점선 줄의 기준 시점이 오늘 갱신 기준인지, 숫자가 원자료와 같은지.
    - 모형 추정(KOFR OIS): CD 공시일이 전 영업일인지, 회의 카드 값과 같은지
    - 한은 점도표: 새 점도표 회의(2·5·8·11월) 뒤에는 그 회의 값으로 바뀌었는지
    - 전문가 전망: 최근 5영업일 보고서만 집계됐는지(기관 수·동결/인상 비율, 그다음 회의 비율)
    - AI 정성 판단: 판단 시각이 오늘인지, 요약 문장이 AI 탭과 같은지
12. **외부 사이트 새로고침 후 나머지 숫자 대조**
    - 회의 카드 2개(가장 높은 결정·확률), 회의 뒤 기대 기준금리표
    - 보고서 탭: 집계 제외(5영업일 지남) 표시, 최종금리 분포
13. **화면 이상** — 빈 칸, 'null', 옛 값이 남은 칸, 콘솔 오류.

## D. 회의 주간에 더 할 것

14. **회의 3영업일 전** — 날짜별 기록과 결정 예측 기록에 그날 값이 남았는지(사후 평가 기준).
15. **회의 당일** — 결정(금리·표결·소수의견)·통방문·간담회 발언 입력, 점도표 공개 회의면 점도표 입력.
16. **의사록 공개일**(회의 약 2주 뒤) — 의사록 수집·위원별 의견 확인.
